# ELS 基坑支护模板工作台

首版基础版本 v0.1，面向Windows。根据已确认计划，以既有Excel计算书及DWG图纸模板为设计依据。

## 已可使用

- 项目、场地、外部验算记录及构件工况内力录入。
- 单位／内力性质检查，位置、标高、重复工况及跨工况几何一致性检查。
- SQLite项目历史版本保存与重开、数据库备份、完整输入项目JSON导入导出。
- 构件平面位置示意，仅读取Excel模板结构及公式样例。
- 模板文件指纹和审核资料检查。

## 当前限制

尚未取得用户的真实模板。当前版本不进行构件安全验算、不自动选型、不生成Excel计算书或DWG/PDF设计图纸。
输入格式检查通过不代表设计通过。模板映射示例不可用于正式设计，准备情况始终明确列出未完成基准验证。

下一阶段须先审查真实模板的计算公式、输入输出单元格、截面与节点库，以及DWG对象映射。
将Excel与AutoCAD自动化接入真实模板后，使用已复核基准项目核对，再开启成果生成功能。

## 启动

本项目电脑已建立 `.venv`；双击根目录的 `启动软件.cmd`。

其他Windows电脑先安装Python 3.12或更新版本，在项目目录执行：

```powershell
./setup.ps1
./启动软件.cmd
```

实际生成阶段还需要Microsoft Excel及AutoCAD桌面版，基础录入不依赖两者。
当前依赖范围见requirements.txt，实际验证版本见requirements-lock.txt。

## 模板资料

将Excel与对应DWG复制到templates目录，另提供一个完整已复核项目及分析来源。
工程模板、项目数据库、生成成果及虚拟环境默认不提交GitHub。
版本库中只保存代码、非工程测试数据和文档。

## 测试

```powershell
./.venv/Scripts/python.exe -m unittest discover -s tests -v
```

SQLite数据库位于data/projects.sqlite3。平面示意只显示构件坐标，不表达支撑连接和几何跨度，不能作为设计图。
