# ELS 基坑支护模板工作台

模板工作台 v0.7.2，面向Windows。根据已确认计划，以既有Excel计算书及DWG图纸模板为设计依据。

## 生成速度与进度提示（v0.7.2）

同一份本机7页验证输入，优化前分析计时143.2秒，优化后正常生成43.8秒，约缩短69%；不包含钢板桩的6页成果实测40.2秒。时间包含Excel启动、验算、检查、保存、PDF导出和关闭；其他项目会随构件数量、电脑和打印环境变化。

生成时在统一按钮下显示当前阶段及活动进度条，完成后显示总耗时。同目录result.json新增performance，包含总耗时和各阶段秒数，便于定位后续慢点。

本次只实施已批准的第一阶段：限制空白尾行处理，使用Excel原生查找替代整张UsedRange读取，批量设置汇总表格式与打印参数，同次生成共享一个只读参考快照，取消重复的指定截面计算。输出仍由真实Excel重算并导出，保留公式错误、独立算式及外部链接检查、NOT PASS成果和既有分页边框。未增加工程计算结果缓存或删除历史模板页。

68项自动测试通过；实际Excel验证全部结果、打印区公式和数值一致，围檩剪力4000kN及动态控制、缺失输入保护继续有效。7页和6页PDF均经过文本、页面尺寸、外框位置及渲染比对。细节及复现方式见[生成性能优化记录](docs/生成性能优化-20261026.md)。

## 围檩剪力焊缝修正（v0.7.1）

按工程师确认，支撑／角撑—围檩焊缝的设计作用力引用**关联围檩构件页J12的设计剪力V**，不引用支撑J11轴力，也不引用支撑自重剪力。围檩V已含1.4，不再重复分项、除间距或作角度换算；支撑截面仍用于计算焊缝有效长度。

自动选控制连接时，根据围檩与支撑的既有关联展开候选，按最大绝对围檩设计剪力选择；Excel通过内部MAX/INDEX保持受力和截面几何同步。缺少关联围檩时要求补充关联，不回退到轴力。注释中的测试例由9899.49kN改为4000.00kN，属于相同输入下的取力修正。新成果保留独立版本，旧成果不覆盖。

## v0.7 统一生成与失败结果输出

所有计算书统一在“围檩／支撑计算书”页点击“生成计算书及 PDF”，钢板桩页只录入及初选，不设置生成按钮。顶部“包含钢板桩计算书”决定是否加入该模块。

生成前检查钢板桩、支撑、围檩、连接、托架及垫层输入。缺少模块数据时显示“XX计算书未输入数据，是否要继续。”选择“是”只生成已完整录入且依赖有效的模块；选择“否”返回继续输入，不改动或清空草稿。若全部模块均不完整，则提示先补充数据。无效数字、公式错误及软件读取失败仍作为输入或运行错误处理。

承载力验算不通过仍输出Excel/PDF：保留不通过的验算结果，结果单元格使用红色背景，页眉标注NOT PASS，result.json记录失败项。不通过不会被误报为通过，也不会自动更换指定型号。

新建围檩的Lx默认跟随Span；手动修改Lx后保留自定义值。新建支撑、围檩的Lx=Ly默认勾选，取消后可分别编辑。托架关联围檩采用已有围檩编号／工况下拉框，删除围檩后失效关联不能作为有效输入。

本机已复现旧BIFF/XLS被Excel拒绝打开的错误，普通打开与内置修复均失败；未将其误判为验算不通过，也不修改Excel安全配置。钢板桩现使用工程师AA文件的原生XLSX页，按同一连续墙方法对齐现有输入输出位置，保留原参考文件。六种截面的剪力、弯矩承载力和刚度均经独立算式核对；无需再打开有问题的旧XLS。实际成果输出为XLSX/PDF。

验证：54项自动测试；tools.verify_v07_excel验证六种型号及含钢板桩、构件、焊缝、Blinding不通过结果的实际Excel/PDF生成。

## 已可使用

- 项目、场地、外部验算记录及构件工况内力录入。
- 单位／内力性质检查，位置、标高、重复工况及跨工况几何一致性检查。
- SQLite项目历史版本保存与重开、数据库备份、完整输入项目JSON导入导出。
- 构件平面位置示意，仅读取Excel模板结构及公式样例。
- 模板文件指纹和审核资料检查。
- 连续钢板桩墙分为两个独立流程：截面初选比较模板六种型号，指定截面验算只验证分析模型已经采用的型号。
- 独立输入各工况未乘1.4的模型剪力、弯矩；使用绝对值包络并记录各自控制工况，由Excel放大1.4一次。
- 选型号后按工程师附表自动读取尺寸、每根／每米墙截面属性与重量，E采用205 kN/mm²，屈服强度采用工程师确认的275 MPa。
- 只需输入设计折减系数（剪力、弯矩共用）和EI折减系数Bd，自动计算EI及折减EI。
- 分析模型直接采用Excel生成EI，取消重复核对环节；自动选型改变型号或刚度时仍提示重新分析。
- 同步两张工作表的Wall Property型号，生成待复核的XLSX副本、PDF及结果JSON；刚度与模型不符时标记须重新分析。

## 当前限制

钢板桩模块已接入本机选定模板的FSPiv Summary第50行，完成六型号及超限软件验证；支撑、围檩、两类直接角焊缝及Blinding已接入计算书模板。尚未完成三个代表工程验证或全部香港规范审核，完整节点设计、整体稳定和DWG出图仍待实施。
输入格式检查或钢板桩两项验算通过不代表整体设计通过。输出始终标记待工程师复核，带lagging的其他组合不纳入本模块。
原模板其他工作表保留为非常隐藏状态以保留公式来源，其中历史错误不代表已处理；它们不参与本模块评估和PDF输出。

本地钢板桩映射位于templates/sheetpile-structure.local.json，不上传版本库。首次导入后使用templates/runtime内的独立参考副本；原参考文件保持打开或另行保存不会触发指纹阻断。公式方法及必需输入的检查仍保留。
项目输入和历史版本包含钢板桩参数。改动输入后，界面会标记先前成果过期；每次生成保留独立版本。模型采用EI由所选型号及Bd生成；旧项目已经记录的模型EI保留，直到修改型号或Bd。

## 启动

本项目电脑已建立 `.venv`；双击根目录的 `启动软件.cmd`。

启动时先弹出Project Setup，填写英文Project Name及Subject Name后进入工作台。这两项随项目版本保存，可在“项目与场地”修改，并直接写入生成计算书的Project／Subject栏。
生成Excel使用英文文件名和表格内容，去除末尾五行说明，内容下方预留一行空白再画粗外框，采用水平及垂直打印居中、0.25英寸窄页边距及自动适配单页。参数来源、控制工况等追溯资料仍保存在result.json。

其他Windows电脑先安装Python 3.12或更新版本，在项目目录执行：

```powershell
./setup.ps1
./启动软件.cmd
```

钢板桩生成需要Microsoft Excel桌面版，基础录入不依赖Excel。CAD目前检测到浩辰CAD，接口和DWG对象映射待验证。
当前依赖范围见requirements.txt，实际验证版本见requirements-lock.txt。

## 钢板桩模块使用

1. 打开“钢板桩结构计算 → 截面初选”，输入两个折减系数和参考内力，比较六种型号及刚度；初选仅保存比较记录，不生成验算XLS/PDF。
2. 点击“采用拟选型号”，型号和系数转入指定截面验算页，原验算内力清空。使用拟选型号及Excel刚度完成外部分析。
3. 在“指定截面验算”填写模型采用的型号、两个折减系数及该型号分析后的内力与来源；已有确定型号可直接使用此页。
4. 到“围檩／支撑计算书”页保留“包含钢板桩计算书”，点击统一生成按钮。软件不更换型号，包含钢板桩的成果位于outputs/sheetpile的独立版本目录。
5. 两页独立保存输入；旧版本自动选型输入转入初选页，不自动用于指定截面验算。初选记录位于outputs/sheetpile-preselection。

软件验证样例位于outputs/sheetpile-validation，明确标注非新项目设计。Excel重算验证脚本为python -m tools.verify_sheetpile_excel，仅在本机真实模板已登记时运行。

## 围檩与支撑计算书（v0.6）

进入“围檩／支撑计算书”，页面顶部填写一次统一工况，点击蓝色“生成计算书及 PDF”按钮。独立生成不要求先填写钢板桩参数；未完整填写的模块经确认后略过。历史多个工况在加载时保留，明确填写统一工况后才替换名称。

- Struts区域：输入未乘1.4的墙法线方向力F（kN）、支撑间距s、角度以及Strut length。角度为支撑轴线与墙法线夹角，设计轴力为1.4F/cos(angle)，不再另乘间距。自重剪力及弯矩使用Strut length，Lx默认跟随它；手动修改Lx后保留修改值。勾选Lx=Ly后，Ly自动跟随Lx。
- Waling区域：选择关联支撑及工况，荷载宽度自动取该支撑间距，分布荷载q=F/s；Span手动输入，整段按均布荷载处理。沿用模板N=1.4qs、V=1.4qSpan/2、M=1.4qSpan²/8。围檩不设置角度。
- 截面下拉框支持输入尺寸片段搜索，例如203；截面属性由原模板库读取。“按选中行批量新增”复制参数并自动生成唯一编号，已录入的关联焊缝也随构件复制。
- Weld页每类连接填写一组参数，无需输入连接构件编号。支撑／角撑—围檩按关联围檩的最大设计剪力选择控制连接，并采用关联支撑的截面计算焊长；围檩—钢板桩按围檩最大设计剪力选择控制构件及工况。计算书保留MAX/INDEX公式，修改内力后控制构件同步变化。选择依据为最大内力，不按利用率排序。
- Kx、Ky、KLT初始为1并锁定。取消该行“设置默认值”后可编辑；已有自定义K值的旧项目保留自定义状态。Lx=Ly采用带文字的大尺寸复选框，勾选时Ly只读。复制行沿用相同列的显示精度，不舍入存储数据。
- Blinding为可选项。勾选后使用钢板桩页剪力包络、项目短边及用户输入厚度，仍采用工程师指定的Blinding模板。未勾选时不要求钢板桩数据、基坑长宽或垫层厚度。

新版独立生成直接使用工程师指定的Structural capacity AA section.xlsx及其中的构件、截面库、Connection check和Bracket工作表，输出XLSX与PDF，不再先打开旧XLS。成果位于outputs/supports的版本目录，文件名Waling_Strut_Check_Review.xlsx/.pdf。输入修改后原成果标记过期；从软件重新生成新版本，以保持结果记录与文件一致。源模板与既有成果保留。

Bracket页输入关联围檩、托架截面及材料、长度L及托架间距。围檩合力作用点固定为L/2，不再输入重心距墙距离。P=1.4×77×Aw/10000×托架间距（kN），qb=1.4×77×Ab/10000（kN/m），V=P+qbL，M=P×L/2+qbL²/2；Aw、Ab均以cm²计。生成表力臂使用L/2公式，并与完整Bracket页联动。焊脚、焊缝强度及总有效焊长统一移到Weld页的托架焊缝区域。若旧项目各托架焊缝参数不同，需在新页面明确统一参数后生成。

围檩—钢板桩、托架及其连接、支撑／角撑—围檩的连接验算集中在Connection Checks同一页，保留模板三段结构。完整托架构件剪力、弯矩、截面及屈曲验算采用AA模板的Bracket页，作为独立明细页输出。托架焊缝沿用模板的直接剪力比较，未增加焊缝群弯矩传递验算；这一范围在托架明细页明确注明。旧模板的固定OK与失效项目引用不沿用。

AA模板登记及导入版本信息保存在本机templates/supports-structure.local.json。更新工程师参考文件后，在页面点击“更新参考模板…”明确导入新版本；不会自动追随原文件的编辑。生成副本移除外部工作簿链接，并检查打印区数值未被断链改变。工程师原参考文件与输出之间不存在活动工作簿链接，原文件不必关闭。Weld与Blinding参数始终可填写，勾选仅决定是否输出；采用自动Span时，手动分配长度无需输入。全部页面共享同一套明暗主题、控件间距及表头风格。

本次界面与数值回归：python -m unittest discover -s tests。原生Excel端到端验证：python -m tools.verify_v06_excel（需本机已导入模板与桌面Excel）。旧tools.verify_aa_connection_links用于历史手入力臂版本，其相关用例不适用于固定L/2的新模式。

旧项目的支撑kN/m值按原间距转换为墙法线力kN，保留原计算轴力和自重长度；能唯一识别的围檩关联自动恢复，无法唯一识别时需手动选择关联支撑。Excel验证脚本包括tools.verify_supports_v2_excel及tools.verify_support_button，要求本机已登记模板和已有基准样例。
